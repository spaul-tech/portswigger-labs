# 💉 SQL Injection

Hands-on notes and lab documentation for learning SQL Injection.

## What is SQL Injection?

SQL Injection occurs when untrusted user input is incorporated into
SQL queries in an unsafe way, allowing the input to alter the intended
query behavior.

## SQL Injection Types

- In-band SQL Injection
- Blind SQL Injection
- Error-based SQL Injection
- Union-based SQL Injection
- Time-based SQL Injection
